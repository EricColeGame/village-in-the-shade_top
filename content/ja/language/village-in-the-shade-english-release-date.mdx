## ゲームプレイと設定：ルールのある居心地の良い農園

Village in the Shadeは、桜、石畳の小道、静かな小川を強く押し出した手描きスタイルで描かれた日本の山間の村、カガツにあなたを連れて行きます。表面上はごく普通のファーミングシムです。作物を植え、農園を拡張・装飾し、それぞれが自分のルーティンを持つ村人たちとの関係を築くのです。

そこへルールが現れます。

| 主要機能 | 内容 |
| --- | --- |
| 農業 | 季節を通じて作物を植え、手入れする |
| 農園のカスタマイズ | 所有地を整え、装飾する |
| 関係性 | 村人と友達になり、彼らについて知る |
| 探索 | 村を歩き、小川のそばに座り、花を眺める |
| 家のルール | 知らない人と話さない、村を出ない、夜に出歩かない |

この3つのルールこそがゲームの本当のフックです。日が暮れてから町を出るなと言うファーミングシムは、可愛らしさで言っているのではありません。カガツには土の下に秘密があることを示しており、リラックスした昼間のループは、夜の緊張感をより強く響かせるために部分的に存在しているのです。

実際的には、これはペース配分が重要であることを意味します。プレイヤーからのコミュニティ報告によると、ゲームはゆっくりしたルーティンを報いるようです。朝に作物の手入れをし、午後は関係構築に使い、村が何を隠しているのかをほのめかす会話に注意を払う。メインスレッドを急ぐと、準備不足で情報不足のままになる傾向があります。
