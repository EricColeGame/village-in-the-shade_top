## Windows에서 Village in the Shade 저장 위치가 보통 있는 곳

대부분의 중소 규모 PC 게임은 몇 가지 엔진 중 하나로 제작되며, 각 엔진은 저장 방식에 고유한 관례가 있습니다. 무작정 찾아다니기보다 먼저 엔진을 파악하세요. 파일 경로에 있는 폴더 이름이 힌트가 되는 경우가 많습니다. 그런 다음 해당 위치를 확인하면 됩니다.

아래 표는 일반적인 위치를 정리한 것입니다. 보장이 아니라 출발점으로 생각하세요. 개발자는 기본값을 얼마든지 바꿀 수 있고, 게임 폴더 이름이 스토어 제목과 조금 다를 수도 있습니다.

| 엔진 / 프레임워크 | 일반적인 Windows 경로 |
|---|---|
| Unity | `%USERPROFILE%\AppData\LocalLow\<Studio>\<Game>` |
| Unreal Engine | `%LOCALAPPDATA%\<Game>\Saved\SaveGames` |
| Godot | `%APPDATA%\<Game>` 또는 `%APPDATA%\Godot\app_userdata\<Game>` |
| GameMaker | `%LOCALAPPDATA%\<Game>` |
| RPG Maker MV/MZ | `%APPDATA%\<Game>` 또는 실행 파일 옆의 `save` 폴더 |
| Steam Cloud wrapper | `Steam\userdata\<AccountID>\<AppID>\remote` |

여기서는 두 가지 간단한 단축 방법이 시간을 아껴 줍니다. **Win + R**을 누르고 `%appdata%` 또는 `%localappdata%`를 입력하면 Roaming 또는 Local AppData 폴더로 바로 이동할 수 있습니다. 그런 다음 **수정한 날짜** 기준으로 정렬하세요. 마지막으로 저장한 순간에 변경된 폴더가 거의 확실히 원하는 폴더입니다.

### 설치 폴더도 확인하세요

일부 게임, 특히 Steam 외부에서 배포되는 게임은 실행 파일 옆이나 게임 디렉터리 안의 `Saves`, `SaveData`, `Profile` 하위 폴더에 저장 파일을 기록합니다. AppData에서 아무것도 맞지 않으면 설치 디렉터리를 열고 해당 이름들을 찾아보세요. 구성 파일이 여기에 있으며, 때로는 저장 경로를 직접 가리키기도 합니다.

## 정확한 폴더를 찾는 빠른 방법

어느 정도 짐작한 경로가 맞지 않으면 검색으로 전환하세요. 이 방법들은 엔진과 관계없이 작동하며, 저장 문제를 자주 해결하는 플레이어들이 실제로 사용하는 방법이기도 합니다.

| 방법 | 하는 방법 | 적합한 상황 |
|---|---|---|
| 확장자 검색 | 드라이브에서 `*.sav`, `*.dat`, `*.json` 검색 | 수천 개 파일을 몇 개로 좁히기 |
| 수정 날짜 정렬 | 검색 결과를 날짜 기준 최신순으로 정렬 | 게임이 방금 기록한 파일 확인 |
| Steam 파일 브라우저 | 게임 우클릭 → 관리 → 로컬 파일 보기 | 게임과 함께 저장된 휴대용 저장 파일 찾기 |
| 파일 감시 도구 | 게임 내에서 저장하는 동안 쓰기 활동 모니터링 | 알려지지 않았거나 이름이 바뀐 경로 찾기 |
| 게임 내 메뉴 확인 | "저장 폴더" 또는 "디렉터리 열기" 옵션 확인 | 경로를 직접 노출하는 게임 |

파일 감시 방식은 결정적이기 때문에 언급할 가치가 있습니다. 가벼운 모니터링 도구를 실행하고 게임을 저장한 뒤 어느 디렉터리에 쓰기 이벤트가 발생하는지 지켜보세요. 나타난 디렉터리가 바로 답입니다. 개발자가 폴더 이름을 알아볼 수 없게 바꿨더라도 모호함은 없습니다.

무언가 설치하는 게 싫다면 저기술 방식으로 해보세요. 정확한 시각을 적어 두고 저장한 다음, 최근 몇 분 내에 수정된 파일을 검색하면 됩니다. 느리지만 결과는 마찬가지로 확실합니다.

## macOS와 Linux에서 Village in the Shade 저장 위치

Mac과 Linux 플레이어는 폴더 관례가 다를 뿐 같은 문제를 겪습니다. macOS에서는 Library 폴더가 기본적으로 숨겨져 있어 많은 사람이 헤맵니다. Finder의 **이동** 메뉴를 열 때 **Option**을 누르고 있거나, **폴더로 이동**을 사용해 경로를 직접 붙여넣으세요.

| 플랫폼 | 일반적인 저장 경로 |
|---|---|
| macOS (네이티브) | `~/Library/Application Support/<Game>` |
| macOS (Unity) | `~/Library/Application Support/<Studio>/<Game>` |
| Linux (네이티브) | `~/.local/share/<Game>` |
| Linux (Unity) | `~/.config/unity3d/<Studio>/<Game>` |
| Linux via Proton | `steamapps/compatdata/<AppID>/pfx/drive_c/users/steamuser/` |

Proton 경로는 북마크해 둘 가치가 있습니다. Windows 게임이 Linux 또는 Steam Deck에서 호환성 계층을 통해 실행되면 저장 파일은 홈 디렉터리가 아니라 가상 Windows 드라이브 안에 있습니다. 해당 `steamuser` 폴더에서 실제 Windows 컴퓨터에서 사용하는 것과 동일한 AppData 구조를 따라가세요. Deck 플레이스루를 백업하려면 게임 설치 폴더가 아니라 그 프리픽스에서 복사해야 합니다.

## 저장 폴더를 중심으로 백업 습관 만들기

Village in the Shade 저장 위치를 한 번 찾는 것은 유용합니다. 하지만 그 위치를 계속 기억하고 여기에 루틴을 붙이는 것이 실제로 진행 상황을 보호합니다. 내러티브 중심 게임의 저장 파일은 보통 작아서 대개 최대 몇 MB에 불과하므로 복사본을 아끼지 않아도 됩니다.

| 주기 | 작업 | 소요 시간 |
|---|---|---|
| 매 플레이 세션 전 | 저장 폴더를 날짜가 붙은 하위 폴더에 복사 | 1분 이내 |
| 매주 | 백업 폴더를 클라우드 스토리지와 동기화 | 설정 후 자동 |
| 중요한 선택 전 | 파일을 복제하고 해당 분기를 위해 이름 변경 | 몇 초 |
| 게임 완료 후 | 최종 저장 파일을 메모와 함께 보관 | 1회성 |

간단한 명명 규칙을 따르면 정리가 쉬워집니다. `save-backup-YYYY-MM-DD-HHMM` 형식을 사용하세요. 알파벳순으로 정렬하면 백업이 시간순으로 자동 정리됩니다. 여러 플레이스루를 보관한다면 짧은 라벨을 붙이세요. `chapter4-beforechoice`는 `backup2`보다 훨씬 많은 정보를 알려줍니다.

### 문제없이 복원하기

복원은 반대 과정일 뿐이지만 한 가지 규칙이 있습니다. 먼저 게임을 종료하세요. 게임은 종료 시 저장 데이터를 자주 다시 쓰기 때문에 프로세스가 실행 중일 때 파일을 복사하면 복원한 파일을 덮어쓰거나 반쯤 기록된 파일이 생길 수 있습니다. 완전히 종료하고 프로세스가 끝났는지 확인한 뒤 백업을 폴더에 붙여넣고 다시 실행하세요. 게임이 클라우드 서비스와 동기화된다면 다시 실행하기 전에 어느 복사본이 우선인지 확인하세요. 오래된 클라우드 버전이 방금 복원한 파일을 조용히 교체할 수 있습니다.

## 문제 해결: 저장 위치가 예상과 다를 때

인디 게임 커뮤니티에서는 저장 파일이 사라진 것처럼 보인다는 보고가 자주 나옵니다. 거의 모든 경우 데이터는 존재하며 경로가 예상 밖의 어딘가에 있을 뿐입니다. 무언가를 잃었다고 단정하기 전에 아래 표를 차례로 확인하세요.

| 증상 | 가능한 원인 | 해결 방법 |
|---|---|---|
| 저장 폴더가 어디에도 없음 | 저장 파일이 설치 디렉터리에 있음 | 게임 자체 폴더 확인 |
| 폴더는 있지만 비어 있음 | 클라우드 전용 또는 샌드박스 저장소 | 클라우드 동기화를 잠시 끄고 다시 저장 |
| 파일은 있는데 게임이 무시함 | 버전 또는 프로필 불일치 | 파일 이름이 정확히 일치하는지 확인 |
| 업데이트 후 저장 파일 초기화 | 빌드 간 경로 변경 | 새 폴더를 검색하고 마이그레이션 |
| 충돌하는 저장 파일 두 개 | 클라우드와 로컬이 분기됨 | 타임스탬프를 비교하고 더 최신 파일 유지 |

참고 자료가 필요하다면 [PCGamingWiki의 Village in the Shade 항목](https://www.pcgamingwiki.com/wiki/Village_in_the_Shade)처럼 커뮤니티가 관리하는 자료에서 저장 경로와 구성 세부 정보를 확인할 수 있습니다. 다만 규모가 작은 게임에 대한 위키 정보는 불완전하거나 일시적으로 제공되지 않을 수 있습니다. 이런 페이지가 부족할 때는 포럼과 Steam 토론에서 공유되는 플레이어 경험이 가장 빠른 정보원인 경우가 많습니다. 읽은 내용을 실제로 적용하기 전에 자신의 파일 시스템에서 확인하세요.

## 자주 묻는 질문

**일반적인 Windows PC에서 Village in the Shade 저장 위치는 어디인가요?**
엔진에 따라 다릅니다. Unity 게임은 보통 `AppData\LocalLow`, Unreal 게임은 `AppData\Local\<Game>\Saved\SaveGames`, Godot 게임은 `AppData\Roaming`에 데이터를 저장합니다. 저장 직후 드라이브에서 최근 수정된 `.sav` 또는 `.dat` 파일을 검색하면 1분 이내에 정확한 폴더를 확인할 수 있습니다.

**저장 파일을 다른 컴퓨터로 옮길 수 있나요?**
네. 가장 최근 파일만이 아니라 저장 폴더 전체를 새 컴퓨터의 동일한 상대 경로에 복사하세요. 일부 게임은 저장 파일 옆에 별도의 설정 또는 프로필 파일을 보관하며, 이것이 없으면 게임이 진행 상황을 유효하지 않은 것으로 처리할 수 있습니다.

**업데이트 후 저장 파일이 사라진 이유는 무엇인가요?**
업데이트는 때때로 내부 폴더 이름을 바꾸거나 데이터를 새 형식으로 마이그레이션합니다. AppData 아래에 이름이 약간 다른 새 폴더가 생겼는지 확인하고, 그 안에서 이전 저장 파일의 타임스탬프와 일치하는 파일을 찾아보세요. 날짜별 백업을 보관하면 이 상황을 치명적이지 않고 복구 가능한 문제로 만들 수 있습니다.

**Steam Cloud를 활성화하면 Village in the Shade 저장 위치가 바뀌나요?**
클라우드 동기화는 로컬 파일을 이동하지 않고 Steam의 `userdata` 디렉터리 아래 원격 복사본에 미러링합니다. 클라우드와 로컬 버전이 일치하지 않을 때 편집, 백업, 복원하는 대상은 로컬 복사본이므로 로컬 Village in the Shade 저장 위치를 아는 것은 여전히 중요합니다.
